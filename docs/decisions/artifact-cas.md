## Language

- **Existence cache**: the server-side cache of positive "this blob exists" results, per organization and backend. It never holds a "not found".
- **Client cache**: the in-memory, short-lived cache of loaded storage clients. Credentials never leave the process.
- **Download token**: the token that allows one download. A browser sends it in the `Authorization: Bearer` header, so the download URL stays the same for a digest. _Avoid_: the `?t=` query parameter for browser downloads, because a changing URL defeats the browser cache.
