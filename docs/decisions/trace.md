## Language

- **Harness**: a coding agent that Trace records, for example Claude Code, Cursor, OpenCode, Pi, or Codex. _Avoid_: "agent" for the product, because the agent is also the model that follows the capture instruction.
- **Provider**: the Trace integration for one harness: its hooks, its transcript parser, and its finders. The provider ID is the harness name in lower case, for example `pi`.
- **Session material**: the AI coding session evidence of one session. It holds the transcript, the file changes, and the spec list. It holds references to spec materials, not their content.
- **Spec source**: an input that sets or explains the task of a session, for example a ticket, a document, an approved plan, or an image. _Avoid_: "the prompt". The user's request prompt is not a spec source, because the transcript holds it.
- **Capture**: the agent writes a spec source into the session spec folder. The CLI captures skills and pasted images itself.
- **Kind** and **Role**: the kind is the format of a spec source (`ticket`, `document`, `image`, `text`, `skill`). The role is its purpose (`task`, `spec`, `plan`, `reference`). _Avoid_: a new kind for a purpose, for example a `plan` kind.
- **Spec entry**: one item of the spec list in the session material. It points to a spec material by digest.
- **Pointer**: a copy of a spec source in the transcript that the CLI replaced with the `chainloop.replaced` marker and the digest of the material. _Avoid_: "placeholder" for this, although the file name of Spec issue-3556 uses it.
- **Placeholder**: the fixed line that the agent writes as the body of a local-file capture. The push replaces it with the file content.
- **Pasted image**: an image the user pasted into the harness. The CLI captures it from the transcript as "Pasted image N".
- **Local mode**: Trace stores sessions on disk with no control plane, set with `traceStorage: LOCAL`. _Avoid_: "offline" (the model is online), "export" (exporting a recorded session is a separate, future feature), `requireTrace` and `localTrace` (use `traceRequired`).
- **Trace directory**: the directory where Trace keeps all its state for a checkout, set with `tracePath`. Default `.git/chainloop-trace`.
- **Net contribution**: the lines a session added that no later commit replaced. It is the AI and human split that Trace reports.
- **Ledger**: the AI line ledger, the fingerprints of the lines that agent edits wrote.
- **Join**: a commit with no session that replaces lines of a session joins that session as human work.
- **Feature table**: the table of the Trace README that marks each feature per harness. The end-to-end suite reads it as the expected result. A **cell** is one harness, model, and feature.
