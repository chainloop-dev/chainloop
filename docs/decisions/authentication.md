## Language

- **Handoff code**: the short-lived, single-use code that the callback carries in place of the token. The client exchanges it for the token. The callback parameter is `handoff`. _Avoid_: `code` as the parameter name, because a client callback can be an OAuth client that already gets `code` from its own identity provider.
- **Legacy callback**: the callback that carries the token in the URL (`?t=`). It is deprecated in three phases.
- **Challenge**: the PKCE-style S256 value that binds a handoff code to the client that started the login.
